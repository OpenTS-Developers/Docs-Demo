# OpenTS Manual Demo

This repository is a temporary, generated mirror of the OpenTS manual while
the main OpenTS repository remains private.

The published site is available at
<https://opents-developers.github.io/Docs-Demo/>.

Do not edit files under `docs/` directly. They are validated static build
output and will be replaced wholesale by the next demo publication. The
documentation source remains alongside the OpenTS engine so contributors can
change behavior and documentation together when the main repository becomes
public.
